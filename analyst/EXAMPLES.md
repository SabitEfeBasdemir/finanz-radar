# Örnek analizler / Example analyses

Okuyucunun beğendiği ve beğenmediği analizler, kısa yorumlarla. Claude yeni analiz yazmadan önce bu dosyayı okur:
beğenilenleri örnek alır, eleştirilen noktalardan kaçınır.

The reader's liked and disliked analyses with short comments. Imitate the liked ones; avoid what was criticised.

Format:

```
## 👍 / 👎  TICKER – başlık (YYYY-MM-DD)
Neden iyi / neden kötü: ...
(İsteğe bağlı: analizin metni veya uygulamadaki bağlantısı)
```

---

(Henüz örnek yok. Uygulamadaki 👍 / 👎 butonlarıyla verilen geri bildirimler `data/feedback.json` dosyasına gelir;
kalıcı olarak saklamak istenenler buraya taşınır.)
